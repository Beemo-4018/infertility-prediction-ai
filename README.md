### 🗓️ 2026-03-14 : 시스템 최적화 및 고급 인코딩 전략 (V6 ~ V7)

> **핵심 진단:** 상위 10개 피처가 중요도의 66%를 차지하는 '정보량 포화 상태' 확인. 피처 수정을 넘어선 모델 튜닝 및 고급 기법으로 방향 선회.

#### 🚀 V6: 리소스 한계 돌파 및 시간 최적화

- **가설:** 학습 시간 부족으로 인한 딥러닝 모델(`NeuralNetTorch`)의 조기 종료가 앙상블 점수를 제한하고 있음.
- **조치:** - `time_limit`을 1시간에서 **2시간(7200s)**으로 확장.
  - 불필요한 노이즈 피처 추가 삭제 및 피처 정예화 (54개).
  - LightGBM의 정교한 분기를 위해 **CPU 학습** 환경 고려.
- **결과:** **0.740327 (최고점 경신)** 🏆
- **회고:** 시간이 늘어남에 따라 AutoGluon이 더 많은 하이퍼파라미터 조합(26개 모델)을 탐색하여 소수점 넷째 자리의 상승을 이끌어냄.

#### 🧪 V7: 타겟 인코딩(Target Encoding) 최종 병기 투입

- **가설:** 범주형 변수의 텍스트 정보를 성공률 기반의 수치 정보로 치환하면 트리 모델이 더 직관적으로 학습할 것임.
- **조치:** - **K-Fold Out-Of-Fold (OOF)** 방식의 타겟 인코딩 적용 (Data Leakage 원천 차단).
  - `시술 유형`, `난자 출처` 등 주요 범주형 변수 6개 대상 적용.
  - 기존 Ordinal Encoding과 Target Encoding 동시 유지 (범주 구분 + 통계 정보 동시 제공).
- **결과:** **0.740213**
- **회고:** V6보다 CV 점수는 미세하게 낮으나, 타겟 인코딩 피처들이 중요도 상위권에 포진함. 일반화 성능(Robustness) 면에서는 V7이 더 안정적일 것으로 예상됨.

## 💡 주요 인사이트 (Key Learnings)

1. **나이(Age)는 절대적인 지표:** 모든 실험에서 나이와 관련된 변수가 압도적인 중요도를 보였으며, 이를 타 시술 지표와 결합(Interaction)했을 때 모델의 변별력이 극대화됨.
2. **노이즈 제거의 마법:** 83개의 피처를 54~59개로 압축했음에도 성능이 유지되거나 상승함. 불필요한 정보(ID, 단순 코드 등)를 제거하는 것이 모델의 안정성에 큰 기여를 함.
3. **앙상블과 시간의 시너지:** 단일 모델의 한계를 딥러닝과 트리 모델의 앙상블로 극복했으며, 충분한 학습 시간(7200s)이 주어졌을 때 비로소 모델의 잠재력이 발휘됨.
